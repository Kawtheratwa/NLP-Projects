# NLP Projects

A collection of Natural Language Processing and Machine Learning projects focused on interactive Arabic web applications.

---

## Projects

### [Itqan — Speech_Quran](./Speech_Quran/)
A web app that helps users memorize the Quran. It listens to recitation through the microphone, verifies each verse one by one, and provides instant feedback.

**Stack:** FastAPI · Web Speech API · Jinja2

---

### [Customer Churn Prediction Bot](./Customer%20Churn%20Prediction%20Bot/)
An Arabic chatbot that predicts whether a customer is likely to leave a company (churn). It collects customer data through an interactive conversation and returns an instant result using a Logistic Regression model.

**Stack:** Python · Flask · scikit-learn · pandas · HTML/CSS/JavaScript

---

### [PPU Chatbot](./PPU_Chatbot/backend/)
An AI assistant for Palestine Polytechnic University (PPU) students. Supports registration, email verification, and is designed to answer university questions grounded in official documents using RAG.

**Stack:** FastAPI · SQLAlchemy · Alembic · JWT · Pydantic

**Status:** Authentication and database are ready — NLP/RAG features in progress.
